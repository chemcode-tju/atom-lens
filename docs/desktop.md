# 独立 Mac App 与 Codex 侧栏

[返回 README](../README.md)

Atom Lens 共用同一套格式解析、轨迹读取、渲染、测量和导出代码，提供独立窗口与 Codex 插件两个入口。当前为 Apple Silicon Mac 的本地预览，尚未发布或完成 Apple 公证。

## 本地文件

将应用拖到 Applications 后直接打开，无需 Codex。使用“打开本地…”或 ⌘O，从上次打开结构的目录继续选择文件。多选时，可以分别打开为标签页，或指定主文件，把轨迹与拓扑等配套文件作为一组打开。也可以拖入结构文件。POSCAR、CONTCAR、XDATCAR 保留原名即可。

打开第一个结构后，顶部出现标签栏。点加号继续打开结构，或用右侧的分屏按钮任选两个标签左右并排或上下排列。可拖动分隔线调整大小，也可交换两个视图的位置。本地结构和服务器结构能放在同一分屏里，各自保留视角、轨迹进度和显示设置。

Mac 自带应用运行环境包含基础标准库。CIF/PDB、部分拓扑处理及动画编码仍需要可选依赖；这些依赖的支持范围见 README。程序不会自动下载科学软件，当前也没有本地科学依赖配置界面。安装 conda 包不会更改 App 的内置环境；需要这些格式时，可使用已配置环境的 Codex 插件，或连接使用该环境的服务器后端。

## SSH 服务器

在“服务器”面板读取现有 SSH 配置，选择 Host 别名或填写 `user@host`。支持 OpenSSH 配置中的端口、密钥和跳板设置，不改写 SSH 配置，不保存密码。需要密钥或 SSH agent 登录；首次主机指纹确认、密码或交互式 MFA 登录应先在终端完成。

列表分为“已保存”和“SSH 配置中的主机”。可以新增多台服务器，分别保存显示名称、SSH 配置文件、主机、Python 路径和 Codex 安装选项。同一主机也可保存不同 Python 环境。点击“保存配置”无需连接服务器；“安装／更新”和“连接”会先保存当前配置。

选择列表项会加载该项配置，点击“连接”才会切换查看主机。启动时自动尝试连接上一台成功连接的服务器，连不上时可以继续查看本地文件。手动断开或移除该配置会清除它的自动重连记录。首次从旧版升级后，成功连接一次即可保存此记录。

配置位于 `~/Library/Application Support/Atom Lens/servers.json`，不存密码或私钥，不随 App 上传到服务器，也不写入安装包。更新 App 时保留列表。旧版尚未持久保存的输入需要首次手动保存。

先“检查环境”，再“安装／更新”，最后“连接”。安装文件由 Mac 上传，服务器无需访问 GitHub，也不需要 sudo。服务器必须已有 Python 3.9+；若默认 `python3` 版本较旧，可填写合适 Python 的绝对路径。尚不支持自动下载 Linux Python 运行环境。

后端安装位置为 `~/.local/share/atom-lens/backend`，仅替换带本程序标记的目录。连接通过 SSH 的标准输入输出传输，不在服务器开放 HTTP 端口。关闭 App 时结束连接；不会启动服务器系统服务。

右上工具区的“查看位置”可在本地 Mac 和已连接的服务器间切换。打开本地文件时保留服务器连接及其标签页。隐藏的标签页暂停播放与后台索引，返回后恢复此前的播放状态。单次运行最多保留 4 台服务器。

空白视图中央的“打开结构文件”和标签栏加号都跟随当前查看位置。每个 SSH 配置独立保存自己的上次打开目录，目录不可用时从服务器主目录开始。安装／更新某台服务器前，会关闭该服务器已有会话。

分屏或窗格偏窄、偏矮时，底栏自动切为单行。点帧号可弹出时间轴，也可输入帧号。播放时拖动，松开后从目标帧继续；暂停时拖动仍保持暂停。单帧结构隐藏播放区。「更多」里可手动开启单行底栏，并在紧凑模式下打开视图、结构信息和播放设置。

加载期间优先读取播放帧，缓存少量邻近帧，并按需推进索引。大体系的实际播放速度仍受渲染性能与 SSH 延迟影响。

远程结构按需读取。查看正在追加的轨迹时维持本次打开范围，重新打开才能读取新增帧。

## 同时使用远程 Codex 侧栏

安装服务器后端时，可勾选“同时安装服务器 Codex 插件”。机器标识为 `structure-viewer@atomic-structure-tools`。连接或检查环境时会核对服务器 Codex 的插件注册状态，并保存最近一次核对结果。本机菜单显示本机 Codex 的注册状态。

然后在**本地 Codex App 通过 SSH 连接该服务器**，重新打开远程聊天，再让 Codex 使用 Atom Lens 打开服务器上的绝对路径，或从侧栏工具入口打开。读取工作发生在服务器，交互界面显示在本地 Codex 侧栏。

独立 App 的 SSH 连接和 Codex 的 SSH 连接是两个入口。独立查看不需要服务器安装 Codex；Codex 侧栏需要服务器上可用的插件 CLI。首次未检测到 CLI 时，先用 Codex 建立一次远程聊天，再回来安装。

## 导出

独立 App 可把当前连接的导出结果直接保存到 Mac，使用系统目录选择窗口，且不会覆盖已有同名文件。远程模式也可选择保存到服务器。图像数据分块传输；动画在当前后端主机上使用 FFmpeg 编码。

Codex 远程侧栏中的“保存到 Mac”继续使用可选保存助手。独立 App 不需要此助手。两种入口的 PNG/JPEG/PDF、动画编码和科学处理限制一致。

## 更新与移除

替换 Mac 应用后，重新安装本地 Codex 插件以绑定新路径；服务器在连接面板中单独更新。不要把 Mac 应用复制到 Linux 运行。

不再使用服务器后端时，可移除其专用 `~/.local/share/atom-lens/backend` 目录；如装过 Codex 插件，先按[卸载说明](installation.md#更新与卸载)移除插件。不会删除结构文件和用户导出。
