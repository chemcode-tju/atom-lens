# Atom Lens 使用手册

[返回 README](../README.md) · [安装与依赖](installation.md)

## 打开第一个结构

仓库自带 [examples/water.xyz](../examples/water.xyz)，包含两个示意水分子帧，不是模拟结果。

1. 在安装插件的主机上打开 Codex 聊天，让 agent 执行：

   > 请用 Atom Lens 在侧栏打开这个仓库的 examples/water.xyz，使用它的绝对路径。

2. 侧栏显示水分子后，在底部时间轴切换两帧；左键拖动旋转，右键拖动平移，滚轮缩放。
3. 也可以从聊天侧栏的“＋／新增标签”工具列表打开 **Atom Lens**，点击右上角文件图标中的“按路径打开”，填写文件的绝对路径。在本地查看时，可用“本地文件”选择或拖入 `water.xyz`。

Agent 使用 `open_structure_path` 直接打开原文件，不需要生成中间文件。普通 `.xyz`、`.extxyz` 等文件链接也可进入文件查看器；若默认显示文本，可在文件查看器切换入口中选择 Atom Lens，入口位置取决于 Codex 版本。

### 界面入口

右上角保留四个图标，悬停可查看名称，点击展开卡片：

| 图标分组 | 功能 |
| --- | --- |
| 文件 | 按路径打开、本地文件、格式识别、当前帧源码 |
| 显示 | 原子样式、配色、半径、晶胞、序号、氢键、Wrap、元素／选中原子显示设置、质心漂移校正 |
| 导出 | 快照、导出动画 |
| 界面设置 | 主题、字号、语言 |

卡片不占据结构视图的布局高度，一次只展开一组；点击外部或按 Esc 收起。下拉列表展开时，Esc 先关闭下拉列表。

播放中可以直接调整显示方式、配色、半径、晶胞、序号、氢键与 Wrap，也可打开显示设置，调整元素／选中原子的显示或应用质心漂移校正；改动即时生效并继续播放。已暂停时调整这些选项不会自动开始播放。

底栏参考 OVITO 的排列：左侧为时间轴，右侧第一行是首帧、上一帧、播放、下一帧、末帧，第二行是帧号和播放设置。单帧结构隐藏整组轨迹控件；后台发现多帧后自动显示。侧栏变窄时先让出时间轴区域，再隐藏旋转／平移等快捷按钮，保留固定大小的播放、帧号、“视图”和“结构信息”入口，不缩小或换行。

播放设置点击展开卡片；帧率、倍速、步长和循环选项即时生效，保持当前播放或暂停状态。清空数字输入框或输入超出范围的值时，暂时沿用上一个有效值。实际播放速度仍取决于读取和渲染耗时。

“视图”卡片集中放方向、单／双／四视图、鼠标操作、适应视图和放大视图。选中原子的测量与坐标继续以视图内浮层显示。

### 粒子、类型与晶胞

底部“结构信息”按钮展开三个页签，关闭后归还视图空间；配色、按钮和表格沿用查看器主题。面板只读，不修改结构文件。

- **粒子**：当前帧的 ID、类型、元素、原始坐标、质量、原子名、残基及电荷；支持搜索、仅看选中、每页 50 个粒子。点击序号可定位选择原子。原始坐标不受 Wrap／质心校正影响，统一为 Å；GRO 的源 ID 可能回绕，左侧序号仍唯一。
- **类型**：保留 LAMMPS type、TOP 力场类型或 TPR 类型编号与名称；同一元素的不同类型分别统计。源文件未提供类型时按元素归类，类型栏显示“—”。质量带 `*` 为元素参考值；显示半径是查看器默认值，不是力场参数。
- **晶胞**：切换晶胞向量／长度与夹角，并查看原点、包围盒、周期方向和体积。缺少晶胞时明确提示，不构造假晶胞。

面板随帧更新，最多每秒刷新四次，关闭时不生成表格。粒子列表分页，避免为大体系一次创建数十万行。GRO 本身没有力场类型、质量或电荷，配套 TOP 才能补齐；TRR／XTC 配套 TPR 时保留这些字段，XTC 配套 GRO 时只展示实际可获得的信息。XYZ/extxyz、VASP、CP2K、ASE traj、PDB、CIF 也使用同一面板，缺失字段显示“—”。

文件卡片的“格式识别”默认为自动，可手动指定 XYZ、VASP、LAMMPS dump／data、GROMACS GRO／TRR／XTC、PDB 或 CIF，再打开文件；适用于后缀不标准的文件。格式选择不能代替所需拓扑、单位或元素映射。

### POSCAR、CONTCAR、XDATCAR 不需要改名

使用上述聊天侧栏入口或让 agent 调用 `open_structure_path`，直接传入 `/work/run/POSCAR` 等原始路径即可。

当前宿主的按扩展名文件关联不能覆盖这些无后缀文件名，因此**普通 POSCAR 文件链接仍可能打开文本**。这不是解析器不支持；无需添加 `.poscar` 等后缀，也不要在外部应用“打开”菜单中寻找 Atom Lens。

## 远程与多文件轨迹

### 推荐：直接打开计算目录

在文件所在主机的聊天中说：

> 请用 Atom Lens 打开 `~/work/run/`，自动识别轨迹和配套文件。

`open_structure_path` 只需 `{"path":"~/work/run/"}`。侧栏“按路径打开”也接受目录，默认自动配对；手动配套路径收在高级选项中。目录内只有一组结果时直接打开，有多条轨迹或多组可能拓扑时显示选择列表，不拼接轨迹。直接打开某个文件也会自动查找配套文件。

- LAMMPS：检查输入文件中的 `read_data` / `include`，以及同目录 data。续跑缺少 data 时，参考 `provenance.json` 中的来源记录，再检查最多两层父目录中原子数兼容的 data；不同质量表不会默默任选。只提取头部、质量／标签和元数据命令，不执行脚本。
- CP2K：识别带 `i =` 步数的 XYZ，优先匹配项目名相同的 CELL，再校验步数。
- GROMACS：TRR／XTC 优先匹配同名 TPR，GRO 查找 TOP；多个可能拓扑需选择。实际读取仍校验原子数，GRO＋TOP 还核对名称和残基。XTC 直接逐帧解码；没有 TPR 时查找 GRO 作为元素／原子顺序参照，仍显示 XTC 轨迹，GRO 原子名无法确定元素时会明确报错。高级选项支持 XTC＋GRO＋TOP。

目录扫描不递归，不进入 `archive`；每目录最多检查 2000 个条目、最多返回 32 组结果。大轨迹只探测头部，LAMMPS 配套文件最多读取前 1 MiB，远端仅返回提取的元数据。特殊命名或元数据缺失时可使用高级选项。

目录中找到明确的轨迹时，默认忽略配套静态结构和诊断 PDB；找到 CP2K `*-pos-N.xyz` 时优先选择坐标轨迹，不把 `*-vel-N.xyz`、`*-frc-N.xyz` 或初始 POSCAR 混入。静态结构仍可以直接按文件路径打开。每帧保护上限为 1,000,000 个原子，已验证 158,559 原子的 GRO／TRR／XTC；更大体系的速度受设备和网络影响，不保证指定播放帧率。GRO 的五位原子编号回绕按文件行顺序处理，内部序号保持唯一。XTC 仅索引帧头，按需传输压缩坐标；每次后台索引最多 64 帧，播放时每批 16 帧。

### 可选：明确指定配套文件

在文件所在主机的远程聊天里，可以直接说：

> 请用 Atom Lens 在侧栏打开 `/work/run/trajectory.dump`，配套读取同一次计算的 `/work/run/system.data` 和 `/work/run/log.lammps`，核对元素映射。直接打开，不生成中间文件。

对应工具参数如下，路径都是**当前远程主机**上的绝对路径：

```json
{
  "path": "/work/run/trajectory.dump",
  "companions": [
    "/work/run/system.data",
    "/work/run/log.lammps"
  ]
}
```

工具名为 `open_structure_path`。一次打开一条主轨迹及其配套文件；不要混入其他计算的拓扑或日志。普通聊天文件链接只携带一个路径，不能自动表达这一组关系。直接打开无需创建清单；只有需要可反复点击的 LAMMPS 文件链接时，才使用可选的 `.svtraj` 清单，示例见 [water.svtraj](../examples/lammps/water.svtraj)。

### 手动打开

在“按路径打开”填写目录或主文件的完整路径（支持 `~/`）。需要覆盖自动配对时展开“高级”，配套文件每行一个绝对路径。这里读取的是**插件所在主机**的文件。“本地文件”则由 Mac 的文件选择器选择文件，不能用它浏览服务器目录。

本地多文件可一起选择或拖放。TOP 有目录层级的 ITP 引用时，优先使用“按路径打开”，保留原来的目录结构。

### 各格式如何配套

| 数据 | 主文件 | 配套文件与行为 |
| --- | --- | --- |
| LAMMPS | atom/custom 文本 dump | 加入同次计算的 data、输入脚本或 log，解析元素映射、单位和边界。支持 `metal` / `real`；质量推断会提示，映射冲突会报错。 |
| CP2K | 坐标 `.xyz` | 加入 `.cell`，按每帧注释的 `i = 步数` 精确匹配，每帧使用自己的晶胞；不是按文件行号配对。缺少所需步或重复步会报错，CELL 可有额外步。CELL 未声明周期方向，按三维周期显示。 |
| GROMACS | `.gro` | 可加入 `.top`，按分子拓扑展开并核对原子数、残基和原子名，以拓扑质量识别元素。 |
| GROMACS | `.trr` | 加入匹配的 `.tpr` 提供元素顺序和周期方向；逐帧从 TRR 读取坐标及晶胞，跳过不含坐标的记录。 |
| GROMACS | `.xtc` | 优先配套 `.tpr`；也可使用 `.gro`，需要力场类型时再加入 `.top`。按需解码压缩坐标及晶胞。 |

GROMACS 的 nm 自动转换为 Å。按路径打开 TOP 时，本地 ITP 引用从 TOP 目录及其子目录解析，标准力场从 GROMACS 库读取；文件选择器方式需一并选择 TOP 引用的本地 ITP，不能保留嵌套目录关系。GRO＋TOP 和 TRR＋TPR 需要[额外依赖](installation.md#可选依赖)。

可先用仓库内的 [water.dump](../examples/lammps/water.dump)、[system.data](../examples/lammps/system.data) 与 [log.lammps](../examples/lammps/log.lammps) 验证 LAMMPS 配套打开。

### 远程加载方式

结构文件保留在服务器。插件先返回首帧，再在服务器分批建立帧位置索引；查看或导出某帧时才传输其完整数据，Mac 侧栏负责渲染。后台扫描未完成时，可浏览已经索引的部分，帧数会继续增长。

缓存最多保留 16 帧，估算预算 64 MiB；单个大帧可以超过预算。**缓存预算不是轨迹文件大小上限**。对正在追加写入的 XYZ、VASP、dump、GRO 和 TRR，首次读取时固定文件末端，只纳入该范围内的完整帧；末尾半帧和之后追加的帧不加入本次查看。配套 log／CELL 也固定读取范围。需要最新内容时重新打开，文件更新通知不会自动重载视图。文件替换、截短或检测到已读内容被改写时仍要求重新打开。ASE ULM `.traj` 会回写文件头，暂不使用此追加容忍模式。更多实现细节见[加载与统一场景](loading-and-scene.md)。

## 保存快照和动画到 Mac

### 本地结构

打开“快照”，设置文件名、格式、DPI、透明背景和裁边，再点击保存。Mac 插件会弹出系统文件夹选择窗口，取消不会写入文件。

### 远程结构：服务器与 Mac 二选一

- **保存到服务器**：默认目录为结构文件所在目录，可填写另一个已存在的绝对目录。同名文件自动追加序号，不覆盖已有文件。
- **保存到本地 Mac**：先在 Mac 安装保存助手，在远程查看器选择“保存到：本地 Mac”，点击“保存到 Mac…”。系统保存窗口出现后，选择本地位置并确认；也可取消。

正常的 Codex SSH 远程聊天**不需要再手动添加 SSH 配置或上传保存脚本**。助手自动发现当前 Codex 活跃的 OpenSSH 主机，沿用主机别名、SSH 配置文件、端口、跳板和认证参数，使用该主机已安装插件里的队列程序。菜单栏“结构快照 → 服务器”显示连接状态。

可同时连接多台服务器，各台保存请求独立处理；多个请求到达时，Mac 保存窗口依次弹出，保存／取消结果返回对应查看器。Mac 选中的路径不会回传服务器。

当前 Codex SSH 连接关闭了连接共享，因此助手另建一条非交互 SSH 通道来接收导出，**并非复用同一条 TCP 连接**。服务器须能通过现有认证非交互登录；助手不会枚举 SSH 配置中的全部主机并逐一登录。自动发现依赖 macOS 上 Codex 的 OpenSSH 进程；其他连接实现不保证自动识别。

### 需要独立连接时

若希望未打开远程聊天时仍监听某台服务器，或使用特殊队列路径，可在菜单栏选“添加独立连接…”，选择 SSH 配置文件和主机，再点“安装脚本并连接”。助手会部署队列脚本；每组配置文件与主机别名独立保存。移除独立配置后，仍活跃的 Codex 主机会恢复自动发现。

| 本地组件 | 位置 |
| --- | --- |
| 保存助手 | `~/Applications/Structure Snapshot Saver.app` |
| 登录启动项 | `~/Library/LaunchAgents/org.structure-viewer.snapshot-saver.plist` |
| 可选独立连接设置 | `~/Library/Application Support/Structure Viewer/connection.json` |

### 导出内容

快照沿用当前活动视图的相机、显隐、样式、原子序号、氢键和光影，不含临时选择圈、测量线、工具栏或坐标轴。PNG 可透明，JPEG/PDF 使用白底；可裁去四周空白，DPI 支持 96/150/300/600。PDF 内嵌栅格图，不是矢量结构图。

“导出动画”支持 GIF/MOV/MP4，可设起止帧、帧率、播放倍速和抽帧间隔；使用白色背景，固定开始导出时的视图与显示设置。编码需要插件所在主机安装 FFmpeg。远程动画也可通过保存助手保存到 Mac。

导出没有人为总文件大小上限，实际尺寸与耗时受 GPU、内存、磁盘及网络限制。当前使用 WebGL 渲染，不含光线追踪。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 旋转／平移／缩放 | 默认左键拖动／右键拖动／滚轮 |
| 快速切换视角 | `X` 看 YZ、`Y` 看 XZ、`Z` 看 XY；按住 `Option` 看反方向，作用于当前活动视口 |
| 复位视角 | 再次选择同一方向；另有适应视图按钮 |
| 点选／框选／反选 | 使用底部图标；任意视图模式下 `Shift`＋左键点击或拖框切换选中状态 |
| 测量 | 按点击顺序：2 原子距离、3 原子夹角（第二个为顶点）、4 原子二面角；5 个及以上显示组成 |
| 显隐与局部样式 | “显示设置”按元素显隐，或为所选原子设置样式与内置配色 |
| 主题、字号、语言 | 右侧齿轮设置，支持简体中文／English |
| Wrap | 独立开关，只沿启用 PBC 的方向折回 |
| 质心漂移校正 | 选参考帧与原子组并应用；随后清除或改变临时选择不会改动已应用的原子组 |

原子序号从 **1** 开始，质心参考帧从 **0** 开始。测量使用当前显示坐标，不自动计算周期最短距离。质心校正按质量加权，先校正再 Wrap；输入应是连续、未折回坐标，它不是自动 unwrap 算法。

氢键依据 N/O/F 供受体的距离与角度筛选，不代表电子结构判定；普通球棍键按距离推断，当前不包含跨周期边界的普通化学键。

## 常见问题

**安装了但没有 Atom Lens 入口？** 先确认插件安装在当前聊天所在主机，重新打开面板／聊天，必要时重连远程聊天或重启桌面端。源码修改不会自动更新安装缓存。

**远程路径提示不存在，窗口却显示本地主机名？** 当前打开的是本地插件。切换到正确的远程聊天，再按原路径打开。

**POSCAR 仍然是文本？** 使用聊天侧栏的 Atom Lens 入口，或让 agent 调用 `open_structure_path`；不要改文件名，外部应用“打开”菜单也不是此入口。

**有“本地 Mac”，点击后不弹窗？** 确认 Mac 菜单栏助手正在运行，“服务器”下目标主机显示已连接，远程也安装了当前插件。若提示助手未连接，检查非交互 SSH 认证；需要口令或交互式二次验证的连接无法直接建立保存通道。更新后重开查看器，避免旧服务继续工作。

**多文件元素识别不对或报配对错误？** 确认文件来自同一次计算，提供完整 data/log、TOP/ITP 或 TPR；CP2K XYZ 必须有可匹配的步号，CELL 必须包含这些步。不要仅凭轨迹显示成功判断元素、单位和晶胞一定正确。

**大文件帧数还在增长？** 后台正在建立索引，可以先看前面的帧。模拟程序可继续向文件追加，本次查看会停在打开时范围内的最后一个完整帧。想查看新增帧时重新打开；不是持续追踪模式。
